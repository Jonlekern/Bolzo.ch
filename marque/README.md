# Logo Bolzo.ch

Police : **Overshoot Gentle Breeze (400)**, de LaFleurStudio, en romain.
Le texte est converti en tracés : les fichiers s'affichent partout sans installer
la police.

| Fichier | Usage |
|---|---|
| `logo-bolzo-rouge.svg` | Logo principal, rouge `#d3121b`, sur fond clair. Pour le site et Shopify. |
| `logo-bolzo-rouge.png` | Même logo en image, 2400 px de large, fond transparent. |
| `logo-bolzo-blanc.svg` | Version blanche, sur fond noir ou sur photo. |
| `logo-bolzo-blanc.png` | Même version en image, 2400 px de large, fond transparent. |
| `logo-klarsicht-rouge.svg` / `.png` | Logo produit KLARSICHT, Malabard 800, rouge |
| `logo-klarsicht-blanc.svg` / `.png` | Logo produit KLARSICHT, blanc |
| `apercu/` | Aperçus des logos sur leur fond, pour la charte |

Le rouge est le même que l'accent des pages produit (`--red` dans la charte de
KLARSICHT).

## Règles
- Ne pas déformer le logo : garder ses proportions.
- Laisser autour un espace vide au moins égal à la hauteur du « o ».
- Pas d'ombre, de contour ou de dégradé.
- Sur un fond clair : rouge. Sur un fond foncé ou une photo : blanc.

## Shopify
Boutique en ligne → Thèmes → Personnaliser → En-tête → Logo : téléverser
`logo-bolzo-rouge.png` (ou le SVG si le thème l'accepte).
